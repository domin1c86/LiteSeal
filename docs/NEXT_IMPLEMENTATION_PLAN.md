## 最终验证

- `npm test`：15 项 Electron/Node、132 项 Rust 通过；此命令默认忽略 20 项数据库用例。
- `npm run test:database`：PostgreSQL 16.14，全部 20 项实际通过，0 失败/跳过；涵盖迁移、原有群事务及新增协作并发、编号隔离、拉黑权限。
- `npm run test:groups:integration`：完整 T20/T21 三客户端场景通过；透明代理仅用于注入 ACK/提交响应丢失和旧信封重放。通过提及重启重试、旧加入阶段置顶隔离、改票计数、关闭拒绝、重新加入无旧资格、隐藏重启保持。
- `npm run test:groups:ui`：真实 Electron Chromium、模拟桌面业务接口，1280×900 与 390×844 各 12 组通过，无 renderer 错误/横向溢出，截图已核对。
- `npm run build`、Rust 格式检查、全 workspace/all-targets Clippy（-D warnings）及核心 ffi 编译通过。保留既有 LNK4098/LNK4099 警告。
- 一次服务就绪复跑失败后，单独完整复跑通过；随后加固实际端口发现，并修复测试子进程继承 RUST_LOG=warn 导致就绪日志不可见的问题。启动加固后的回归单独记录，失败报告按时间保留。

报告与截图在忽略目录 `target/test-results/`，不包含数据库密码、私钥、令牌或真实用户内容。专用测试库为 `liteseal_test_t21_4f313d6c7233`；临时凭据只在本轮测试进程环境中保存。容器和专用库保留，未删除或覆盖现有数据。
