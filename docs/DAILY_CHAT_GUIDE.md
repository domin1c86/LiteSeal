# 日常单聊说明

## 身份和历史

当前内测账号绑定原设备与原密钥，不支持换机登录、添加设备或替换密钥。普通退出保留本机密钥和历史。密码不能恢复丢失的密钥；仅复制数据库也不能恢复原设备身份。请勿为了处理登录错误删除密钥文件。

## 消息状态

| 界面状态 | 含义 |
| --- | --- |
| 待发送或等待服务端确认 | 尚未获得服务端持久保存的确认；重试沿用原编号 |
| 服务端已保存 | 密文由服务端保存，仍在等待接收设备确认 |
| 目标设备已保存（非已读） | 接收设备在本地持久化后已发送 ACK，不表示用户阅读 |
| 部分目标设备已保存（非已读） | 只有部分目标设备确认保存 |
| 旧版投递确认（非已读） | 历史协议状态，不据此推断阅读 |
| 对方离线，尚未确认设备送达 | 离线提示，不等同设备接收 |
| 投递失败，可重试原消息 | 可使用“重试原消息”，避免重新发送造成重复 |

本机未读计数只表示本机查看状态；当前没有“对方已读”功能。

## 删除、编辑和撤回

从本机删除会隐藏本机聊天、摘要和未读计数，为链校验保留加密记录；不会删除对方副本、终止已经进行的投递或擦除引用/转发快照。

编辑和撤回仅允许原发送设备在服务端首次接收后 48 小时内执行。撤回同步为不可用占位；对方离线时稍后补收。已经查看、复制、截图或转发的内容不会被全局擦除。

## 图片与文件

单聊可通过“选择文件或图片”或拖入一个原生文件暂存附件；在聊天输入区按 Ctrl+V 可粘贴图片或已复制的文件。发送前可以预览图片并确认，停止传输会保留原任务以便继续。剪贴板图片转为 PNG 后在内存中交给 Rust 加密，PNG 超过 11 MiB 时请先保存为文件再选择发送；普通文件上限为 20 MiB。附件下载完成与消息设备送达是两个不同状态。

## 交付与验收

代码实现不等于双 Windows 验收。安装、断线重试、离线补收、乱序、ACK 丢失和晚到编辑/撤回需要按照任务清单记录实际结果；本机自动化结果见功能实现记录。
