# T22 加密备份与离线恢复

## 2026-10-02 接续：确认历史授权收件（UTC）

v3 档案现包含已确认的 `authorized_history_transfer` 收件原包和原生核对后的便携收件证据，恢复以目标自己的独立密钥重验根签名、原批次/操作/媒体和确认范围。授权包内明确包含的完整媒体是不可拆分签名历史的一部分，普通“包含附件”选项不剥离它；导出前界面说明这一点。统计按唯一消息编号去重，原投递与副本重叠不重复计数。隐藏、较新迁移修订和撤回继续阻止旧正文及媒体读取。

源端准备/中继任务、未确认收件、部分分块及进度均不导出；恢复不激活身份或队列，不生成 ACK/未读/通知。旧 v1/v2 拒绝遗漏式导出含授权或暂存的新数据。专项、实际加入桌面和最终完整回归见 [验收记录](P0_P1_ACCEPTANCE_RECORD.md)，实际跨用户/机器与系统中断仍待执行。

## 2026-10-02 接续：v3 选中身份备份与独立离线读取（UTC）

新增认证载荷版本 3，沿用口令密钥派生与分块认证容器；v1/v2 导出及读取保持，旧版读取器的版本白名单拒绝 v3。桌面从当前选中的原设备或加入档案取实际身份/数据库，允许没有原设备身份文件的机器导出已选加入档案。只在原生见证核对与同一 SQLite 读事务内取得快照，不把生产见证、代次或任务复制到便携档案。身份的访问/刷新凭据清空。

便携 `backup_direct_*` 表使用代码拥有的固定结构：钉住根及完整签名授权事件、当前身份全部已确认原批次/接收元数据与隐藏标记、已确认编辑/撤回原操作 wire、加密草稿及静音/已读偏好。包括操作先到但原消息尚未到的证据；保留原消息的本机顺序，隐藏与撤回在读取和输出时继续阻止正文/媒体。新草稿记录不带原准备消费编号，偏好不带通知领取状态。待发、原操作任务/编号栅栏、ACK、在线会话、补收游标、传输意图/暂停/进度和部分下载全部排除。

可选媒体只取已经确认消息对应的完整本机密文，核对原描述、分块/总摘要并解密认证后包含；暂存未提交、缺失、部分或损坏的缓存记为未包含。撤回/隐藏后已保存的完整缓存可以保留在档案中，但业务 Reader 不能读出。仅传公开名称/MIME/大小及包含状态到页面，文件密钥留在 Rust；独立 `directV3` 业务范围避免与旧群/单聊附件混用。

恢复先验证便携表、索引和触发器结构，拒绝视图或异常定义，再按固定结构重建；逐条核对目录、原签名批次、缓存正文与原密文、完整操作链、偏好范围和全部包含媒体。原发送设备没有自收件密文，新增 `Batch::open_authored` 用原收件设备公钥与原作者私钥认证对应承诺，不把本机缓存单独当作签名正文证据。只读 Reader 在私有内存投影中复用验签/解密逻辑，不安装高水位、不暴露 Store、网络、ACK 或任务调度。

离线窗口新增 `direct_v3` 会话、独立分页游标、编辑版本/撤回占位、草稿/静音展示和认证媒体预览/另存为。不能编辑、撤回、发送、标已读、下载缺失附件或激活身份。源码短测、Chromium 与实际桌面 IPC 的执行结果见 [验收记录](P0_P1_ACCEPTANCE_RECORD.md)；跨 Windows 用户/机器、真实系统中断与独立审查继续待验收。

## 2026-10-03 传输暂停与调度不改变备份白名单

发送意图、暂停标记、重传与下载进度都属于当前身份待发/传输状态，不进入旧 T22。暂停的完整上传缓存也不能当作已提交的离线历史附件；部分下载不能作为认证完成缓存。运行时退避与轮转游标不导出，恢复档案不能启动调度。当前 v3 数据仍拒绝旧格式备份，v1/v2 不变；后续新格式继续排除待发任务及其传输状态。

## 2026-10-03 已准备重传游标不进入旧备份

原媒体恢复游标属于当前身份的待发任务状态，认证保存在 Rust 媒体任务中；不加入 T22 v1/v2 白名单，不将未确认发布的完整本机密文当作已下载离线附件。旧本机任务缺少游标可读，活动恢复仍保留原批次/描述/密文；这不是便携备份或跨机激活途径。v3 历史/草稿/偏好/媒体仍拒绝旧备份，后续新格式必须排除待发与恢复中任务。

## 2026-10-03 桌面媒体预览不改变备份格式

本批的认证另存为是用户明确选择的普通附件输出，不是明文聊天导出。媒体预览暂时生成认证媒体临时文件并由主进程删除，不写明文私钥；恢复档案窗口没有开放这些在线 v3 接口。既有群和 T22 v1/v2 回归另记。

## 2026-10-03 v3 下载缓存仍不进入旧备份

新增部分下载和完整认证缓存沿用当前身份媒体任务；旧 T22 仍明确拒绝这些 v3 数据，没有更改 v1/v2 格式或白名单。部分下载/Failed/Unavailable 不能当作完整离线附件。后续新白名单须验证原可见认证描述及完整密文，排除未提交上传、取消和部分下载，恢复仍不联网或继承在线授权。

本轮只验证共享核心：当前身份已有认证缓存可在签出或远端过期后读取，清理缓存后过期附件不可用；隐藏后拒绝信息和读取。此处不代表 T22 已展示 v3 媒体，也不代表另一 Windows 用户/机器恢复通过。

## 2026-10-02 v3 媒体暂存的防遗漏规则

新增当前身份媒体任务/缓存时，T22 旧白名单明确拒绝导出，包括只有暂存、没有历史/草稿/偏好的身份。取消后明确清理的任务只保留不含文件密钥的原编号标记，该标记按未提交任务数据排除；已有 v3 历史仍由原规则拒绝导出。新增单项短测实际验证这一边界，没有生成静默遗漏媒体的备份。

独立密文分块不是认证完成的离线附件；目前尚未接入新版备份格式。后续需从当前可见认证消息描述读取完整密文缓存，排除暂存、待发及部分下载，并保持只读、无网络和隐藏规则。现有 T22 v1/v2 格式、DPAPI 恢复和群缓存行为保持，实际群回归另记。

## 使用与范围

账号面板选择“备份与隔离恢复”，使用独立口令和一个不存在的新 `.lseal` 文件。口令按 UTF-8 为 12–1024 字节，无法重置。包含当前设备身份、联系人及信任记录、单聊/群历史和链证据、已接受的编辑/撤回/回应/阅读记录、群协作、隐藏标记、草稿、收藏/便笺/列表及本机偏好。

不包含访问/刷新令牌、Windows 密码、应用锁凭据、待发/定时任务、未提交操作、待发 ACK、未知表或旧独立 beta 引擎数据。附件默认不包含；可选完整且认证有效的下载缓存，不补下载或包括上传/不完整下载任务。当前桌面仍是单身份模型，数据按用户、设备与群 scope 筛选，不提供账号间合并。

登录页也有“离线恢复备份”，不需要原服务器在线。输入口令并选择文件，隔离校验完成后打开独立只读窗口，可核对两组指纹、分页查看历史/草稿/回应/投票和保存或预览已有附件。删除、撤回、隐藏继续生效；缺附件或联系人密钥时显示不可用。恢复不替换当前数据、不重置密码、不接管原设备。

档案不运行聊天、群轮询、定时发送、ACK 或任何网络任务。其窗口使用独立 IPC 白名单和 `connect-src 'none'`；原账号窗口的在线工作不会改用档案数据。关闭、系统锁屏、应用锁、休眠、退出或身份变化使档案句柄失效、取消任务并拒绝迟到结果。后台最多一个任务；取消派生阶段需等待本次派生结束。

## 文件与安全边界

- SQLite Backup API 取得一致快照，再以代码白名单重建数据库，不复制运行中的 DB/WAL，也不执行备份的 DDL。SQLite 档案不是 SQLCipher；载荷沿用原身份加密，不能宣称全库加密。
- v1 头为 `LSEALB01`，Argon2id v1.3 固定 3 次/256 MiB/随机 16 字节盐，secretstream XChaCha20-Poly1305 随机 24 字节头。公开头参与块认证。首块为加密清单及无令牌身份，随后为最多 1 MiB 的数据库块，最后是空 FINAL 块；块长度为小端 u32。拒绝非法参数、错口令、篡改、截断、重排/重复和尾随字节。
- 数据库导出/恢复上限均为 8 GiB。附件核对加密描述、原消息和完整认证内容。身份公私钥在 Rust 内校验，恢复密钥重新由目标 Windows 用户 DPAPI 保护；不写明文私钥或聊天导出，文件内容不经过 stdio 桥接。
- 导出先写同卷临时密文，再通过无覆盖硬链接提交。目标需支持硬链接，建议 NTFS 本地目录；不支持时明确失败。恢复失败不改原库或密钥。
- 恢复档案是临时查看会话，正常关闭移除隔离目录。崩溃可能遗留 DPAPI 密钥和加密载荷目录，不自动导入账号，不承诺物理安全擦除。原备份由用户保存。
- 密钥泄露或设备被撤销后，已有备份仍可能解密过去历史，服务器不能远程销毁离线文件。正式覆盖恢复、失密恢复及在线换机另立实现阶段。
