# UI 风格基准与回归

更新：2026-09-30。设计基准为 Git 提交 `da66ac0`。本次只调整桌面 React 界面及交互容器，不回退协议、业务接口、存储或后续功能。

## 基准调研

直接读取该提交的 `ui/src/theme.css`、`App.tsx`、`ContactList.tsx`、`Chat.tsx`、`Login.tsx`、`StorageManager.tsx` 等源文件，并在隔离 Electron 中使用相同虚构数据渲染旧版与当前组件。

- 原有主题变量在本次调整前与 `da66ac0` 一致：浅色白底/浅灰侧栏；深色 `#0f0f0f` 工作区、`#161616` 侧栏；反色主按钮和自己发送的气泡。
- 保留 `liteseal▌` 等宽字标、280px 桌面侧栏、约 58px 会话标题栏、840px 内容宽度，以及 6/8/12px 圆角层级。
- 沿用系统浅深色切换，不额外增加与基准无关的品牌色、渐变或装饰。
- 偏差主要出现在裸按钮、选择框、文本域与后续功能的排布。基准提交中也已有少量未统一的消息操作/侧栏按钮；本次将这些控件一并纳入既有设计规则，而非逐像素复制当时的问题。

## 界面与操作

| 区域 | 调整后方式 |
| --- | --- |
| 顶部 | 紧凑账号、群聊、锁定入口；右侧连接状态；保存状态独立显示 |
| 会话列表 | 保留聊天/联系人标签、筛选与归档；每行 `···` 展开置顶、归档、静音 |
| 单聊 | 旧版左右反色气泡；`···` 展开复制、收藏、回复、删除、转发、编辑、撤回及回应选择；已有回应保持可见 |
| 输入区 | 统一带边框的输入框；emoji 弹层；下方紧凑附件、语音与定时消息入口 |
| 编辑/撤回/删除/转发 | 统一模态窗，包含焦点、关闭后恢复焦点；提交期间禁止关闭；错误在窗内显示 |
| 群聊 | 相同灰阶侧栏、标题、气泡和输入框；“管理群聊”展开邀请、静音、补收、群数据及成员管理操作 |
| 群协作 | 保留提及、置顶、投票及全部状态；投票采用主题卡片，选中项使用反色 |
| 账号/整理/锁定 | 与旧版存储弹窗一致的边框、圆角、字体层级和控件；账号与整理窗口使用原生模态焦点隔离 |
| 窄窗口 | 单聊保留紧凑侧栏；群聊上下分区；菜单、输入区及弹窗适配 390px |

菜单支持键盘展开、Escape 关闭与点击外部关闭。群管理仍遵守既有权限：普通成员不会获得群主操作。登录、联系人身份核实、双指纹邀请、确认清理和危险操作的流程保留。

## 可复现检查

```powershell
npm run test:ui:style
npm run test:groups:ui
npm test
npm run build
```

`test:ui:style` 编译真实 React 组件，在临时 Electron 配置目录中运行。业务接口全部模拟，姓名、消息、指纹与账号均为虚构；不访问真实用户数据库、密钥目录或服务端。

- 浅/深色各检查 1360×1000 与 390×844；每组合 15 张截图，共 60 张。
- 覆盖登录、注册、聊天、联系人、账号、整理、存储、锁定、编辑、搜索、定时、附件、emoji、群聊与群数据窗口。
- 检查横向溢出、弹窗视口边界、首条消息菜单裁切、外部点击/Escape、焦点进入/恢复、编辑输入、忙碌关闭保护、窗内提交错误及已有回应可见性。
- 每次生成 `target/test-results/ui-style-*/result.json`、`index.html` 图册及 PNG。失败保留本轮证据；不纳入 Git。
- 群交互仍通过既有 `test:groups:ui` 验证邀请、静音、提及、置顶、改票、关闭、冲突、草稿、清理与会话生命周期。菜单测试会先展开实际入口。

本次 `npm test`：15 项 Electron/Node 与 132 项 Rust 通过；20 项 PostgreSQL 用例在常规测试中忽略。本次没有重跑专用数据库或真实三客户端入口，不把之前的通过结果当作本次执行。生产构建通过，既有 LNK4098/LNK4099 链接警告保留。系统通知、双 Windows、安装和独立安全验收仍属另项；不改变 T20/T21 验收勾选。

本次最终截图证据：`target/test-results/ui-style-3aaRbd/`，60/60 截图与四种主题/尺寸组合下的 6 组交互检查通过，无 renderer 错误。群交互证据：`target/test-results/group-ui-O4dUzn/`。完整测试与构建日志：`target/test-results/ui-refresh-npm-test.log`、`target/test-results/ui-refresh-build.log`。这些路径为本机忽略产物，克隆仓库后可用上述命令重新生成。
