# 单聊正在输入提示（T18）

## 已交付行为

- 每个本机账号默认关闭，可在账号设置中启用“向联系人显示我正在输入”。仅输入框实际变更触发发送，恢复草稿或打开会话不触发。
- 客户端最多每 3 秒刷新一次；停止输入 4 秒、清空文本、发送、失焦、切换会话、打开遮挡面板或锁定应用时停止。接收端断线立即清除；未收到停止事件时最多保留到服务端给出的 5 秒有效期，排队过期事件不会重新显示。
- 输入状态仅经已认证 WebSocket 转发，不生成消息编号、消息链、ACK、离线对象或聊天历史。SQLite 只保存账号开关，不保存输入活动。

## 权限和兼容性

服务端从当前连接获得发送者身份，收件人必须已允许该联系人，且双方没有相应拉黑/拒绝策略。转发入队及真正写入收件连接前都检查权限。未知身份、离线、拒绝和拉黑均无状态响应，不能用返回值探测对方活动。

单连接每分钟最多接受 60 次状态变化，同一活动状态刷新至少间隔 2 秒。满队列时事件直接丢弃，不进入持久队列。状态来源由服务端认证，不是独立端到端签名；服务端能看见这些活动元数据，用户需主动启用。

认证新增可选 `supports_typing`，缺省为 `false`。新服务端只向显式声明支持的在线连接发送输入事件，旧客户端可继续收发原有消息。使用 T18 需更新客户端和服务端；Android 工程未提供对应界面。有效期使用系统时间，实机验收需包含时钟偏差场景。
