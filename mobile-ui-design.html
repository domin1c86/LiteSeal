android ui design · react native · v1 full parity 移动端界面设计

Single-pane phone adaptation of the desktop "codex look": mono wordmark, hairline borders, square avatars, flat bubbles, mono metadata, color-coded trust labels. Navigation: bottom tabs (chats / contacts / settings) with chat & contact-detail pushed on a stack. 桌面端「codex 风格」的单栏手机适配：等宽字体标识、细线边框、方形头像、扁平气泡、等宽元数据、彩色信任标签。导航为底部三个标签页（会话/联系人/设置），聊天与联系人详情为堆栈推入页。

design notes 设计说明

  • Theme tokens are lifted 1:1 from ui/src/theme.css (this page uses the exact values); RN gets them as a TypeScript constants module with dark default and light via the system color scheme. 主题令牌与桌面端 theme.css 完全一致，RN 侧以 TS 常量模块实现，深色为默认，浅色跟随系统。
  • Navigation: react-navigation — bottom tabs (chats / contacts / settings) + native stack for chat, contact detail; add-contact is a bottom sheet. Android back pops the stack, then backgrounds the app. 底部标签 + 原生堆栈；添加联系人为底部弹层；安卓返回键先出栈再退到后台。
  • Messages: inverted FlatList; delivery ticks map to local-store delivery states (✓ sent, ✓✓ acked); integrity-failed messages are withheld with a danger flag, matching desktop behavior. 倒序 FlatList；✓/✓✓ 对应本地送达状态；完整性失败的消息以占位+红色警示呈现，与桌面一致。
  • Touch targets ≥ 44dp everywhere (rows 66dp, tab bar 56dp, buttons 44–48dp). 所有可点击区域不小于 44dp。
  • States covered: keyboard avoidance (01, 03), unread badges (02), offline banner + amber dot (07), trust tri-state (04), key-change warning (05). 已覆盖键盘避让、未读角标、离线横幅、三态信任标签与密钥变更警告等状态。
